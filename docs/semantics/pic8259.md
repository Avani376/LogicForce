# Semantics: 8259 Programmable Interrupt Controller (Phase C7)

Status: **CONTRACT for Phase C7** (implemented in `engines/pic8259/`)
Engine version: 0.1.0 · Extends `interrupts.md` (8086 interrupt layer)

## What the model covers

A deterministic, educational model of one Intel 8259 PIC driving the 8086 INTR
line: the IRR/ISR/IMR registers, the ICW initialization sequence, OCW
operation words, fully-nested priority with rotation, the EOI family, and the
vector numbers delivered to the CPU. Everything is a pure function of the
request/config; no wall time, no sampling. Results are labeled
`EXHAUSTIVE(k)` where k is the number of scheduled events — every event is
processed, every state transition is shown.

## Out of scope (honest boundaries)

- Cascade (multiple PICs, slave INT routing): ICW3 is parsed and recorded when
  the sequence requires it, but cascade routing is not simulated.
- Level vs edge triggering: requests are explicit events (pulses). LTIM is
  recorded, not behaviorally simulated.
- Poll mode, special shell-out, and INTA pulse timing in bus cycles.

## Registers (8 bits each)

| Register | Meaning |
|---|---|
| `IRR` | Requests raised, not yet serviced |
| `ISR` | Levels currently in service |
| `IMR` | Mask: bit=1 blocks that line from *service* (IRR still records it) |

## Programming sequence (state machine)

1. `ICW1` — must be first. `IC4` (bit 0): ICW4 required when 1. `SNGL` (bit 1):
   0 ⇒ ICW3 required next. `LTIM` (bit 3): recorded.
2. `ICW2` — vector base for IR0. **Must be a multiple of 8** (8086 mode);
   otherwise typed `PicError(BAD_VECTOR_BASE)`.
3. `ICW3` — required only when `SNGL=0`; recorded, no cascade simulation.
4. `ICW4` — required when `IC4=1`. `AEOI` (bit 1): automatic EOI on
   acknowledge. `SFNM` (bit 4): recorded.
5. OCWs (`OCW1/2/3`) are rejected with `PicError(NOT_INITIALIZED)` until the
   sequence completes. ICW1 at any time re-initializes (documented real-chip
   behavior): all registers clear, priority resets, init restarts.

Vector delivered for line `n`: `base + n`.

## Priority resolution

- Default: IR0 highest … IR7 lowest (fully nested).
- A rotation command sets a **priority floor**: the line just below the floor
  becomes highest. `rank(line) = (line - floor - 1) mod 8`.
- A request on line `n` is serviceable when: `IMR[n] = 0`, IRR bit set, and —
  in normal mask mode — `rank(n)` is better (lower) than the best rank among
  set ISR bits, or ISR is empty. In **special mask mode** (OCW3 ESMM+SMM) ISR
  bits do not block service; only IMR does (documented simplification).
- `int_vector()` returns `base + n` for the best serviceable line, else None.
- `acknowledge()` moves that IRR bit to ISR (clears IRR, sets ISR) and returns
  the vector. With AEOI the ISR bit is cleared in the same operation.

## OCW2 — EOI family (R bit 7, SL bit 6, EOI bit 5, LEVEL bits 2:0)

| R | SL | EOI | Command |
|---|----|-----|---------|
| 0 | 0 | 1 | Non-specific EOI: clear the best-rank ISR bit |
| 0 | 1 | 1 | Specific EOI: clear `LEVEL` (must be in ISR) |
| 1 | 0 | 1 | Rotate on non-specific EOI: clear best ISR bit, floor ← that line |
| 1 | 1 | 1 | Rotate on specific EOI: clear `LEVEL`, floor ← `LEVEL` |
| 1 | 0 | 0 | Set priority: floor ← `LEVEL` (no ISR change) |

`OCW1` sets IMR directly. `OCW3` toggles special mask mode (ESMM+SMM /
ESMM+¬SMM) and selects the register returned by status reads (IRR/ISR).

## Trace (reproducible evidence)

Every state transition appends `{ "at_step": k, "kind": …, … }` with kinds
`request`, `deliver`, `ack`, `eoi`, `mask`, `rotate`, `smm`. Same-step events
process in the order listed by the caller (stable). The delivery trace maps 1:1
onto `cpu8086.ScheduledInterrupt(source="intr", number=vector, at_step=k)` —
the end-to-end test runs a PIC-derived schedule through the real CPU pipeline
and asserts one ordered trace.

## Errors

`PicError` (subclass of `LogicEngineError`) with categories:
`NOT_INITIALIZED`, `INIT_SEQUENCE`, `BAD_VECTOR_BASE`, `BAD_LINE`,
`BAD_OCW`. Message is actionable; all validation is fail-fast at the call.
